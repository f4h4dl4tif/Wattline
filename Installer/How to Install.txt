How to install Wattline
=======================

Requires macOS 14 Sonoma or later. Runs on Apple Silicon and Intel Macs.
The charge limit needs Apple silicon and macOS 26.4 or later.

Wattline isn't notarized by Apple, so on a new Mac macOS blocks it the
first time. Pick ONE of the two ways below, and use the Terminal fixes if it
fails.


OPTION A: Installer package (Wattline-x.x.pkg)  <- recommended
---------------------------------------------------------------
1. Double-click Wattline-x.x.pkg.
2. If macOS says it "can't be opened" or "could not verify" it: click Done,
   open System Settings > Privacy & Security, scroll to Security and click
   "Open Anyway" next to Wattline-x.x.pkg. Enter your password.
3. Follow the installer. Wattline is installed in Applications and opens
   itself. The package also lets Wattline switch Low Power Mode without a
   password.


OPTION B: Disk image (Wattline-x.x.dmg)
---------------------------------------
1. Open the .dmg and drag Wattline onto the Applications folder.
2. Open Wattline from Applications. If macOS blocks it, click Done (don't
   move it to the Bin), then System Settings > Privacy & Security >
   "Open Anyway".
   (With the disk image, macOS asks for your password the first time you
   switch Low Power Mode from Wattline.)


IF IT STILL FAILS: Terminal commands
------------------------------------
Open Terminal (Applications > Utilities > Terminal), paste a command, press
Return and type your Mac password when asked (nothing shows as you type).

1. The installer package won't open. Install it from Terminal instead
   (change the path if the file isn't in Downloads):

       sudo installer -pkg ~/Downloads/Wattline-*.pkg -target /

2. Wattline is installed but won't open, or macOS says it is "damaged":

       sudo xattr -cr /Applications/Wattline.app && open /Applications/Wattline.app

3. "Open Anyway" doesn't appear, or the .pkg / .dmg itself is blocked:

       xattr -c ~/Downloads/Wattline-*

   then double-click the file again.

4. Notifications or the calendar warning never ask for permission, or keep
   saying permission is denied:

       tccutil reset All local.wattline.Wattline

   then quit and reopen Wattline and allow the prompts again.

5. Check the Mac is new enough (must say 14 or higher):

       sw_vers -productVersion


AFTER INSTALLING
----------------
Click the battery in the menu bar, or press Option-Command-B. A welcome tour
walks you through the choices the first time. To hide macOS's own battery
icon: System Settings > Control Center > Battery.

Widget: right-click the desktop > Edit Widgets, and search for Wattline (or
open Notification Center > Edit Widgets). If it doesn't appear, open
Wattline once from /Applications, then run:

       pluginkit -a /Applications/Wattline.app/Contents/PlugIns/WattlineWidget.appex
       killall chronod NotificationCenter

Shortcuts: Wattline Settings > Shortcuts & Widgets lists the commands to
paste into the Shortcuts app (for example "Get battery time left").

To uninstall: quit Wattline from its panel, then run

       rm -rf /Applications/Wattline.app ~/Library/Application\ Support/Wattline
       sudo rm -f /etc/sudoers.d/wattline
